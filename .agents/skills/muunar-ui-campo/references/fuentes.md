# Fuentes

Estas reglas son una adaptación al web de campo de las guías oficiales de Apple
(claridad, concisión de lenguaje, feedback de carga, accesibilidad) y de
prácticas de diseño de producto, cruzadas con las skills comunitarias y la
documentación técnica del stack.

## Guías oficiales

- Apple Human Interface Guidelines — Clarity, Feedback, Loading, Accessibility.
  https://developer.apple.com/design/human-interface-guidelines/

## Skills comunitarias de diseño

- `emilkowalski/skills` — apple-design.
- `dickwu/apple-design-skill`.
- `motiondivision/ai-kit` — patrones de Motion.

## Documentación del stack

- Motion (Framer Motion): https://motion.dev/docs/react
- Tailwind CSS 4 y `@theme`:
  https://tailwindcss.com/docs/theme
- Next.js App Router (versión del repo): ver
  `node_modules/next/dist/docs/` antes de tocar convenciones de Next.
